# Static Field

`StaticField` shows a read-only label and value laid out like a form field, so it lines up with editable fields around it. For an editable field shown read-only, pass `readOnly` to that field instead.

<ArgTypes />

## Behaviors

- `children` render only when `value` is empty, so you can pass formatted content (a link, a tag) instead of a string.
- `labelStyle` defaults to the surrounding `PresentationProvider`. Only `"above"` and the deprecated `"left"` change the layout; any other style renders as `"above"`.

## How to use

```tsx
<StaticField label="Project" value={project.name} />
<StaticField label="Status">
  <Tag text="Active" type="success" />
</StaticField>
```
