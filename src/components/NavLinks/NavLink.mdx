`NavLink` is a navigation link, or a button when `onClick` is a function, styled for the app's navigation. `SideNav` and `Navbar` render these from their `items`, so use `NavLink` directly only for custom navigation, such as a brand link in the `Navbar`.

<ArgTypes />

## Behaviors

- `variant="side"` styles it as a `SideNav` row, and `variant="global"` for the dark `Navbar`.
- A string `onClick` renders an anchor; `openInNew` opens it in a new tab.
- `active` marks the current page.
- `iconOnly` with an `icon` hides the label visually but keeps it for screen readers, as in the collapsed `SideNav` rail.
- `nested` indents the link for use inside a group.
