# Selected Option Pill

<p className="sbdocs-figma">
  <a href="https://www.figma.com/design/62R8KiDklvgBBSH0mQGWHo/BEAM_27_LIBRARY?node-id=2741-2077">

    Selected Value Pill
  </a>

`SelectedOptionPill` shows one value selected from a field. Use × to remove it.

It is wider than a filter pill so it can hold richer values, like a code plus a name. Long values are clamped at two lines. Use `SelectedOptionPillList` to stack several beneath a multi-select field.
