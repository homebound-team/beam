# Selection Summary Pill

<p className="sbdocs-figma">

`SelectionSummaryPill` stands for a group of selections, shown as a count and an object, e.g. "3 Rows Selected". It always shows Clear, and the whole pill is the button. It is a summary rather than one value, so it is slightly more prominent than a [Filter Pill](?path=/docs/components-pills-filter-pill--docs).
