# Pills

A pill is a rounded control for an active selection that can be cleared. Unlike a tag, which is an informational label and not interactive.

Use × to remove one selection.

See [Filter Pill](?path=/docs/components-pills-filter-pill--docs) and [Selected Option Pill](?path=/docs/components-pills-selected-option-pill--docs).
