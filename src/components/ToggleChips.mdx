`ToggleChips` renders a wrapping list of `ToggleChip`s, one per value, and calls `onRemove` with the value whose chip was clicked. Use `Chips` for read-only values.

<ArgTypes />

## Behaviors

- `getLabel` provides each chip's text, which also serves as its key, so labels should be unique.

## How to use

```tsx
<ToggleChips
  values={selectedTrades}
  getLabel={(t) => t.name}
  onRemove={(t) => setSelectedTrades((ts) => ts.filter((x) => x !== t))}
/>
```
