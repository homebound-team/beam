# Button Group

`ButtonGroup` joins related choices or actions into one control. It comes in two styles:

- **Text**, a view toggle, e.g. switching between Cost and Price. Exactly one button is `active`, and selecting another changes the view immediately.
- **Icon**, a set of related actions, e.g. previous, add, and next. These are actions, so none of them is `active`. Give each one a `tooltip`.

Use two or three buttons. If you need more, use a select field instead. Write text labels in title case with no punctuation, and keep them to one or two words.

## Behaviors

- The group is always 40px tall, matching text fields.
- The selected button is the only one with the blue fill. It has no hover or pressed state, because clicking it does nothing.
- Hover and pressed use gray fills, never blue, so they can't be mistaken for a selection.
- Each button gets a test id from its text, or its icon if it has no text. For example, "Cost" gives `buttonGroup_cost` and its tooltip `buttonGroup_cost_tooltip`. Pass `data-testid` to change the `buttonGroup` prefix.

## How to use

A view toggle:

```tsx
<ButtonGroup
  buttons={[
    { text: "Cost", active: view === "cost", onClick: () => setView("cost") },
    { text: "Price", active: view === "price", onClick: () => setView("price") },
  ]}
/>
```

A set of actions:

```tsx
<ButtonGroup
  buttons={[
    { icon: "chevronLeft", tooltip: "Previous", onClick: onPrev, disabled: !hasPrev },
    { icon: "plus", tooltip: "Add", onClick: onAdd },
    { icon: "chevronRight", tooltip: "Next", onClick: onNext, disabled: !hasNext },
  ]}
/>
```
