## Behaviors

- The fill ends in a hard stop. It only gets a rounded end once it reaches 100%.
- The label is rounded down to a whole number, so it never reads 100% before the bar is full. The fill uses the exact value.
- The label always takes the same width, so bars stacked in a column line up no matter their values.

## How to use

`ProgressBar` fills its container's width. Wrap it to set the length.

```tsx
<div css={Css.w("40%").$}>
  <ProgressBar value={65} />
</div>
```

Cards get one by passing `progress` to `CardBody`, or `cardProgressSlot` in a card view. Those set the width for you.
