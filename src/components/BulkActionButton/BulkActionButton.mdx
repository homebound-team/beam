# Bulk Action Button

`BulkActionButton` (the Selection Action Button in Figma) summarizes a selection and is the entry point to its bulk action, e.g. "Edit 3 Rows". Clear removes the whole selection. Each side is its own button and tab stop. It is a sibling of the [Selection Summary Pill](?path=/docs/components-pills-selection-summary-pill--docs), which shows a count with no action.

In a `GridTableLayout`, pass `bulkCta` rather than rendering this directly.

- Write the label as [Verb] [Count] [Object], e.g. "Assign 3 Rows". Don't add "Bulk", and use title case with no punctuation.
- Use the pencil for edit and assign actions.
- The active blue fill means a selection is active. Don't reuse it for other toolbar buttons.
