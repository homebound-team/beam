`Chip` is a small, read-only rounded label, such as a category or a selected value shown in a table cell. Use `Chips` for a list of them, `ToggleChip` when the user can remove it, `Tag` for a status, and `ContextTag` for what something is.

<ArgTypes />

## Behaviors

- `type` sets the fill and defaults to `neutral`.
- Long text is cut to one line. `title` adds a tooltip below the chip, e.g. with the full text.
- `compact` defaults to the surrounding `PresentationProvider`'s `compact` setting.

## How to use

```tsx
<Chip text="Electrical" />
<Chip text="Over budget" type="warning" icon="error" />
```
