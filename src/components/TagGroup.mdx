`TagGroup` shows a wrapping list of outlined (`secondary`) tags, such as the labels on an item, with an optional Edit control. Use `Tag` for a single status.

<ArgTypes />

## Behaviors

- `onEdit` adds a trailing "Edit" text button. A function makes it a button; a string makes it a link.
- Each tag's `text` is its key, so the texts should be unique.

## How to use

```tsx
<TagGroup tags={item.labels.map((l) => ({ text: l.name }))} onEdit={() => openLabelEditor(item)} />
```
