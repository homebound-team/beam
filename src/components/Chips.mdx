`Chips` renders a list of `Chip`s with even spacing. Use `ToggleChips` when each one can be removed.

<ArgTypes />

## Behaviors

- `values` takes plain strings, or `{ text, title }` objects to give each chip a tooltip.
- The chips wrap onto new lines unless `wrap` is `false`. `wrap` defaults to the surrounding `PresentationProvider`'s setting, so a table can keep them on one line.

## How to use

```tsx
<Chips values={["Framing", "Drywall", "Paint"]} />
```
