`ToggleChip` is a removable chip: text with a trailing `x`, such as a selected value the user can clear. Use `ToggleChips` for a list of them, and `Chip` when it can't be removed.

<ArgTypes />

## Behaviors

- A click anywhere on the chip calls `onClick`, not just on the `x`.
- `disabled` hides the `x` and blocks clicks.
- Long text is cut to one line, with the full text in the native tooltip.
- Inside a compact `PresentationProvider`, it uses the smaller chip size.

## How to use

```tsx
<ToggleChip text={vendor.name} onClick={() => removeVendor(vendor.id)} />
```
