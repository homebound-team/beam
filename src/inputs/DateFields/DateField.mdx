`DateField` picks a single date, typed in or chosen from a calendar popover. Use `DateRangeField` for a start and end date. In a form, use `BoundDateField`.

<ArgTypes of={DateField} />

## Behaviors

- Values are `PlainDate`s (Temporal), and `onChange` receives `undefined` when the field is cleared.
- `format` sets how the date displays: `short` (01/01/20), `medium` (Wed, Nov 23) or `long`. Focusing the field switches it to `short` so it's easy to edit.
- A typed date that can't be parsed is reverted to the last value when the field loses focus.
- Clicking the field or the calendar button opens the picker. The field doesn't bring up the on-screen keyboard on touch devices.
- `disabledDays` takes dates, lists, ranges or a function, to block days in the picker.
- `onEnter` runs on Enter and then blurs the field.

## How to use

```tsx
<DateField label="Start date" value={startDate} onChange={setStartDate} format="medium" />
```
