## Usage

Use `MenuMultiSelectField` when a filter accepts several values. It takes `values` and calls `onSelect(values, options)`. Each row has a checkbox, the menu stays open while options are toggled, and the closed field shows a count badge. A selection hidden by the current search stays selected.

Plug into `@homebound/form-state` with `BoundMenuMultiSelectField`.

See [Select fields (new)](?path=/docs/inputs-select-fields-new--docs) for shared implementation details and remaining work.
