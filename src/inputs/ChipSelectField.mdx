# Chip Select Field

`ChipSelectField` is a single select that looks like a compact chip and opens a menu of options. Its label is visually hidden, so it fits inside dense rows like table cells. For a standard labeled select, use `MenuSelectField`. In a form, use `BoundChipSelectField`.

<ArgTypes />

## Behaviors

- `onSelect` receives the chosen value and its option. Clearing (with `clearable`) calls it with `undefined` for both.
- `onCreateNew` adds a "Create new" action to the menu. Choosing it swaps the chip for a text field, and the typed name is passed to `onCreateNew`.
- When options have `id` and `name`, `getOptionValue` and `getOptionLabel` can be left out.
- The chip uses the `sm` type scale unless a `PresentationProvider` sets `typeScale`.

## How to use

```tsx
<ChipSelectField label="Phase" value={phaseId} options={phases} onSelect={(id) => setPhaseId(id)} clearable />
```
