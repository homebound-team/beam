`RichTextField` is a rich text editor for notes and comments, with `@` mentions. For plain multi-line text, use `TextAreaField`. In a form, use `BoundRichTextField`.

<ArgTypes />

## Behaviors

- `value` is HTML. `onChange` receives the HTML, its plain text, and the mentions it contains. Content that's only whitespace is reported as `undefined`.
- Typing `@` shows `mergeTags` in a popup. `mergeTags` is read once; later changes aren't picked up.
- `readOnly` renders the HTML as formatted text, with no editor.

## How to use

```tsx
<RichTextField
  label="Comment"
  value={comment}
  onChange={(html) => setComment(html)}
  mergeTags={teamMembers.map((m) => m.name)}
/>
```
