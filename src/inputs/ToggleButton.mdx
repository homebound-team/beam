`ToggleButton` is a small, borderless button that switches between on and off, with an optional icon. It turns blue while selected. Use it for view toggles in toolbars and headers; use `Switch` for a labeled setting. It has no `Bound*` wrapper.

<ArgTypes />

## Behaviors

- When `onChange` returns a promise, the button is disabled until it settles.
- `disabled` can be a reason (any `ReactNode`), shown in a tooltip above the button.

## How to use

```tsx
<ToggleButton label="Show delays" icon="flag" selected={showDelays} onChange={setShowDelays} />
```
